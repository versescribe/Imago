# 隐私与本地数据

## 本地处理

截图、OCR、滚动拼接、贴图和录屏均在本机执行。没有账号、分析埋点、广告或崩溃自动上传。
声音采集默认关闭；只有录屏设置中明确启用后，开始录制才打开所选音频设备。

## 更新请求

默认在启动约 10 秒后检查更新，距离上次尝试至少 24 小时；常规设置可关闭，下次启动生效。
主窗口和托盘可随时手动检查。关闭自动检查不影响手动请求。

请求仅发送到 `https://api.github.com/repos/versescribe/Imago/releases/latest`，使用系统代理和 TLS 校验。
GitHub 会收到正常连接所需的 IP 和包含 Imago 版本的 User-Agent。请求不携带令牌、设备标识、图片、文字、录像或音频。
不跟随 API 重定向；响应限制为 256 KiB，检查正式版本及对应 x64 ZIP 是否准备完成。

发现更新仅提示。点击下载按钮才使用系统浏览器打开官方仓库 Release 页面；浏览器后续网络行为由浏览器管理。
Imago 不自动下载、安装或运行更新。

## 本地文件与剪贴板

| 位置 | 内容 |
| --- | --- |
| `%LOCALAPPDATA%\Imago\settings.ini` | 快捷键、窗口吸附、强调色、动画与更新检查偏好 |
| `%LOCALAPPDATA%\Imago\updates.ini` | 上次更新检查尝试的时间，用于限频 |
| `%LOCALAPPDATA%\Imago\Recordings` | 录屏暂存文件及失败时可恢复的文件 |
| 用户选择的位置 | 保存的 PNG 或 MP4 |
| Windows 剪贴板 | 用户主动复制的图像、识别文字、颜色或视频文件引用 |

录像不会在复制、另存、关闭窗口或退出程序时自动删除，以保持文件粘贴有效。可以从托盘打开录像目录，在完成粘贴后自行清理。
应用内截图／贴图不自动保存，关闭后释放内存。

开机自启仅在用户启用后写入当前用户的 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\Imago`。
移动 EXE 不会自动迁移启动项，请在新位置重新保存设置。
