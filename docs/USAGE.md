# Imago 使用指南

## 截图与标注

按 **Ctrl + Alt + A** 框选区域，选区附近出现单行纯图标工具栏：**截图、录屏｜标注工具、颜色与样式、撤销、重做｜取色器、长截图、OCR｜贴图、保存、复制、退出**。左端两个按钮是并列的模式入口，当前截图模式高亮；右端叉号退出。取色器紧邻长截图左侧，这三个功能放在同一组分隔线之间；长截图图标为上下两个箭头，OCR 图标为四角框内的 T。悬停可查看名称与快捷键，按钮保留供辅助功能读取的文字名称。

标注入口默认显示向右的箭头工具，旁边的展开标记根据面板实际位置朝上或朝下，展开后指向相反方向。点击后，在主工具栏附近展开一条横向纯图标选择条，依次为 **箭头、矩形、圆形／椭圆、文本、实色遮盖、像素马赛克、模糊马赛克、选择标注、调整选区**；选中绘图工具后自动收起，入口显示所选工具。颜色与样式入口同样使用随位置、展开状态变化的标记。再次点击入口、点击画布、Esc 或右键可收起面板；此时 Esc／右键只收起，不退出截图。

点击一级工具栏的颜色按钮，直接打开「颜色与样式」面板：上排选择线粗／字号／马赛克颗粒或强度，下排选择颜色，底部保留自定义颜色和删除标注。颜色、粗细可连续调整，面板保持展开；不再经过工具选项菜单。完成框选后默认进入箭头标注，调整截图范围可按 C 或从横向工具条选择。

窗口吸附默认开启：开始截图后，鼠标经过窗口时预览其边界，单击选中整个窗口，再复制、保存或标注。直接拖动仍是自由框选；按住 Shift 可临时跳过吸附。边界来自截图开始时可见顶层窗口的快照，不包含窗口阴影，不自动识别网页内部控件，也不恢复被遮挡的内容。

- 标注保留为独立对象。点击选中后可以拖动、调整控制点、修改颜色和线宽／字号、删除或撤销。矩形和椭圆从边框选中，箭头从线段选中；绘制矩形／椭圆时按住 Shift 可约束为正方形／正圆。
- 文字使用原生多行编辑框，支持中文输入法。编辑时显示圆角底板、留白和强调色焦点边线，从单行高度开始随内容增高，到达选区底部后在框内滚动；白色／黑色等文字会自动搭配清晰的编辑底色，底板和提示文字不会进入截图。Enter 换行，Ctrl + Enter 或 Tab 完成编辑，Esc 取消本次文字修改；再次编辑可双击文字，或在文字工具下点击它。文字编辑时的复制、粘贴和撤销由输入框处理。
- 颜色按钮直接显示当前颜色。样式面板提供八种常用色的横向色块，以及「自定义颜色…」：打开 Windows 系统选色器，可从色域选择、输入 RGB 数值、添加自定义色。自定义色槽在本次程序运行期间保留。为已选标注改色支持撤销，切换绘制工具保留所选颜色；实色遮盖单独记忆颜色，初始为黑色。
- 线粗与颜色在同一个面板中，提供粗细预览和 2 / 3 / 4 / 6 / 10 五档；文字工具显示 18 / 24 / 32 / 48 / 64 字号，马赛克显示颗粒／强度。选中已有对象时修改该对象，否则修改当前绘制设置。实色遮盖不使用线粗。
- 马赛克有两种类型：**像素马赛克**对原图做块平均并保留方块边缘；**模糊马赛克**在缩小的原图上进行三轮可分离均值模糊，再平滑放大。两者都可拖出矩形、移动、调整范围、删除和撤销，颗粒／强度提供 8 / 12 / 20 / 32 / 48 五档，数值越大效果越强。
- 选中已有马赛克，再从横向工具条切换类型，或按 M / Shift+M，直接改变该区域并支持撤销；调整强度同样作用于选中对象。两种效果均绘制在文字、箭头和实色遮盖下方，后加效果不会擦除已有遮盖；预览、复制、PNG、贴图与 OCR 使用同一份合成结果。需要完全覆盖内容可使用实色遮盖。
- 取色模式显示像素放大预览、HEX 和 RGB。单击或 Enter 将颜色用于当前标注／后续绘制；Ctrl+C 复制 HEX 文本并继续取色，Esc 或右键返回编辑。采样的是截图开始时冻结的原始像素，不含标注和暗色遮罩；此模式下工具栏临时隐藏。
- 「调整选区」模式下，拖动边缘或角点调整范围，拖动内部移动范围，外部拖动重新框选。标注仍固定在原来的屏幕坐标，仅输出新选区内的部分。
- 复制、PNG 保存、贴图共用同一合成逻辑；输出包含标注，不包含编辑控制点。文字超出其文本框或选区的部分会裁切。
- 保存使用 Windows 原生对话框，默认时间戳文件名并记住上次目录。保存成功结束截图，取消保存返回当前编辑；不自动保存截图。
- 工具栏支持 Tab 切换、空格激活；按钮获得焦点时 Enter 激活该按钮。标注和颜色按钮可用上下方向键或 F4 展开／收起，横向工具条内用左右方向键切换；样式面板内左右键切换同排选项、上下键切换行，Esc 收起并返回入口。画布获得焦点时 Enter 复制截图。V / R / O / A / T / B / M / C 快捷键可直接切换工具。

## 录屏

主窗口或托盘点击 **开始录屏**，直接进入录屏模式并框选区域；也可先框选，再点击工具栏左端的 **录屏图标**，沿用当前选区。进入此模式不会立即采集声音或录制视频。

- 准备工具栏为 **截图、录屏｜重新框选、电脑音频、麦克风、分辨率、帧率｜开始录制、退出**，左端模式切换和右端退出按钮与截图工具栏一致，当前录屏模式高亮。四个设置按钮点击后展开原生下拉菜单，菜单跟随主题配色，当前项以圆点标记；空间不足时向上展开，箭头随展开方向和打开状态变化。
- 开始前可拖动边缘调整区域、拖动内部移动、在外部拖动或点击「重新框选」选择新范围。方向键微调位置，Shift + 方向键每次移动 10 像素；Tab 将焦点移入工具栏，左右键／Tab 切换按钮，Enter／空格激活，上下键／F4 打开设置菜单。菜单中的 Esc 只收起菜单。
- 开始前点击左端「截图」切回截图编辑，原有选区和标注保留。右端叉号、Esc 或画布右键退出整个选区界面。录屏只录制开始后的实时画面，截图中的标注不会写入视频；开始后锁定模式，需先结束本次录制。
- **电脑音频**和**麦克风**每次进入录屏都默认关闭，图标显示静音；开启后以强调色提示。两个下拉菜单均提供「关闭」「系统默认」和本机当前可用设备名称：电脑音频选择扬声器／耳机等输出设备，麦克风选择具体输入设备。每次打开菜单刷新设备列表，已选择但断开的设备会标为不可用。系统默认在开始时解析，明确选择的设备按 ID 打开，失败时提示重新选择，不自动改录其他设备。仅查询设备名称不会启动音频采集。
- 两路声音可独立或同时开启；同时开启时混成一条 AAC 音轨，并降低各路增益以减少叠加失真。均关闭时不打开音频设备、不创建音轨；设备或权限不可用时会提示，保留截图供重试。
- 分辨率下拉菜单提供 **原始、720p、1080p、1440p、2160p**，默认原始。按所选规格的 16:9 边界等比缩小，不放大小选区；菜单及悬停提示显示实际输出尺寸。H.264 要求宽高为偶数，必要时向下取整，画面不拉伸到固定 16:9。
- 帧率下拉菜单提供 **15、24、30、60 FPS**，默认 30 FPS。性能不足时跳过迟到的视频帧，保持时间轴，不积压无限帧队列。
- 点击「开始录制」或在选区按 Enter，立即进入准备／录制，不再先选择保存路径。开始后截图遮罩收起，录制鼠标指针；控制条显示计时、暂停／继续、停止和退出。暂停时长不计入视频。
- 实际选区用主题色细边框提示，暂停时变为弱化颜色。边框允许鼠标穿透，边框与控制条都从采集画面中排除。Windows 可能同时显示围绕整块显示器的黄色采集提示：它表示显示器正在被采集，最终视频由 Imago 按选区裁剪后编码；黄框不表示最终输出尺寸。Windows 的提示针对采集项，不能直接改成裁剪区域形状，关闭它另有系统授权要求，见 [系统采集边框说明](https://learn.microsoft.com/en-us/uwp/api/windows.graphics.capture.graphicscapturesession.isborderrequired)。
- 点击「停止」后打开结果工具栏：**播放、复制、保存、关闭**。播放使用系统默认播放器；复制按钮或 Ctrl+C 复制 MP4 文件，适用于资源管理器及接受文件粘贴的聊天软件，不保证所有输入框都能粘贴视频。使用标准 [CF_HDROP 文件剪贴板格式](https://learn.microsoft.com/en-us/windows/win32/shell/clipboard#cf_hdrop)，不会把整段视频塞进剪贴板内存。
- 保存按钮或 Ctrl+S 此时才打开 Windows 保存对话框；取消返回结果工具栏，保存失败仍可复制或重试。实际复制文件在后台执行，工具栏显示进度；右端叉号可以取消保存并退出，原暂存录像保留。成功复制或保存后收起结果工具栏。
- 录制中的叉号或工具栏 Esc 会结束并退出录屏，已录内容保留在暂存目录；「停止」会进入结果工具栏。结果工具栏的叉号只关闭工具栏，不删除视频。右键托盘也可停止录屏，或打开录像暂存目录。录制时点击托盘或截图快捷键会唤起控制条；正常退出程序会先停止并完成录像收尾。
- 录像写入 `%LOCALAPPDATA%\Imago\Recordings`，包括复制后的文件和退出录制时保留的文件。暂存文件不会在关闭窗口、退出程序或另存后自动删除，避免使已复制的视频失效；可从托盘「打开录像暂存目录」找到录像并手动清理，不需要保留的文件应在完成粘贴后删除。
- 视频使用系统 H.264 编码器，音频使用 AAC，输出 MP4。优先请求硬件编码，初始化失败时尝试系统软件编码；不保证每台设备能达到所选分辨率和帧率。边录边写入暂存目录，停止时完成 MP4 索引；另存时先写目标目录的独立临时文件，刷新并关闭后再替换目标。发生编码／收尾错误时尽量保留临时录像并提示，文件可能不完整。
- 需要 **Windows 10 2004 或更高版本**及可用的 Windows 媒体组件、D3D11 视频处理能力。当前支持**单显示器内的固定区域、SDR 输出**；跨屏区域会提示重新选择，HDR 色彩、受保护画面、远程桌面需另行适配。系统可能在被采集显示器周围显示捕获提示边框；显示器断开、尺寸改变或音频设备失效时会停止并尽量保存已录部分。暂不支持录制时修改范围、设备热切换、HDR 色调映射或视频编辑。

## 滚动长截图

在目标应用内先滚到需要截取的起点，按 **Ctrl + Alt + A** 框选可滚动内容，再点击一级工具栏的 **长截图图标**，或按 **Ctrl + Shift + S**。程序激活原窗口，将鼠标移到选区中心，默认自动向下滚动；采集面板可随时切换「↑ 向上」「↓ 向下」或「手动」。

- 尽量只框选正文，避开浏览器工具栏、固定侧栏、悬浮按钮和视频。选区必须位于同一个应用窗口中，至少 120 × 240 个物理像素；添加标注后需先撤销标注才能开始长截图。
- 采集过程中显示实时缩略预览，用强调色方框标记当前画面的位置。面板优先放在选区右侧，空间不足时依次选择左侧、其他显示器或上下空位；全屏选区时放在角落，采样时临时隐藏，避免把面板拼进长图。
- 鼠标可以在选区内自由移动。移出选区或移到面板时仅停止发送自动滚轮，回到选区后自动继续，不再因偏离中心 8 像素而永久暂停。点击「手动」后不再发送自动滚轮，点击任一方向按钮可恢复自动采集。
- 选区内的物理滚轮操作会自动切换到手动模式，支持上下滚动和中途反向；系统无法报告滚轮事件的设备可先点击「手动」。向上补入顶部、向下补入底部，回看已经采集的区域不会重复加长图片。建议匀速慢滚，快速跳过超过一屏仍可能因没有重叠而停止。
- 按 **Esc** 或控制窗口的「完成」保留已经拼好的部分。Esc 被其他程序占用时仍可使用按钮。
- 「取消」返回原来的截图选区，不修改剪贴板；目标页面已发生的滚动不会自动恢复。初始截图是冻结画面，重新选择起点时可退出截图并再次框选。
- 自动滚动连续三次画面没有移动时切换到手动，提示「画面未移动」，面板保持打开，可反向继续或完成。切换方向后等待按钮释放，再恢复目标窗口和鼠标位置；切换前尚未完成的滚动不会计入新方向的无变化次数。
- 匹配器区分零位移与对齐失败，移入选区产生的局部悬停变化不会直接按拼接失败结束。单次对齐失败先在原位置重试；仍无法对齐或画面持续变化时切为手动，保留预览和最后可靠帧，可少量反向滚动恢复。自动滚轮带有来源标记，避免被识别为手动滚轮接管。不降低拼接置信度，也不将对齐失败的画面直接加入长图。
- 切换应用、移动／关闭目标窗口或达到采集上限时停止并保留已有部分。只有第一帧时仍可预览、复制或保存它，状态栏说明停止原因。
- 完成后打开原生长图预览窗口，可用滚轮、滚动条、方向键、Page Up/Down、Home/End 浏览。顶部图标支持复制（Ctrl+C）、保存 PNG（Ctrl+S）、OCR（Ctrl+Shift+C）、贴图（P）和关闭（Esc）；复制和保存使用完整像素。预览按窗口宽度适配，不依赖整张图上传为 Direct2D 纹理。
- 单次上限为 5 分钟、120 次自动滚动、60,000 像素高度或 128 MiB 拼接像素，以先达到者为准。最多保留 4 个长图预览窗口；长图仅存在内存中，关闭前需自行复制或保存。
- 使用 Win32 `SendInput`、GDI 捕获和自带的 C++ 双向重叠匹配；仅在采集期间注册鼠标 Raw Input 用于滚轮接管，结束时注销，不拦截目标应用的输入。无 OpenCV、浏览器扩展或第三方运行时。暂不支持横向滚动；管理员应用、整页滚动设置、嵌套滚动区域、重复内容和动态布局可能无法匹配，不保证适用于所有应用。

## OCR 文字识别

框选完成后点击主工具栏 **OCR 图标**，或按 **Ctrl + Shift + C**。成功后按识别行顺序复制纯文本到剪贴板，保留换行并结束截图；原有 Enter / Ctrl+C 仍复制图片。文字输入框正在编辑时，先按 Ctrl+Enter 完成编辑，再触发 OCR。

- 采用 Windows 自带的 `Windows.Media.Ocr` 和 Windows SDK 的 C++/WinRT 头文件，不使用云端服务，不下载或打包第三方模型，不需要安装 .NET 或 WinUI。
- 识别在后台工作线程进行；识别期间暂停修改当前截图，按 Esc、右键或取消按钮会停止识别并回到编辑。窗口关闭后会取消任务，迟到的结果不会覆盖剪贴板。
- 使用当前选区合成后的图像，包含文字标注、实色遮盖和马赛克；不读取被实色遮盖覆盖前的原图内容。
- 没有识别到文字、缺少语言包或系统 OCR 不可用时保留截图，并给出提示；识别失败不写入剪贴板。复制失败也会保留截图，可以再次触发 OCR。
- 默认按 Windows 用户语言偏好创建识别器；没有匹配项时尝试本机其他可用 OCR 语言。此行为不是自动检测截图语言，通知会显示实际使用的语言。识别语言取决于已安装的 Windows OCR 语言包，安装方式可参考 [Microsoft OCR 语言包说明](https://learn.microsoft.com/en-us/windows/powertoys/text-extractor#supported-languages)。Imago 不自动安装语言组件。
- 超过系统 `MaxImageDimension` 的图像会等比缩小后识别，并在成功通知中说明。细小文字可通过缩小选区或放大原始内容改善；不保留表格、字体样式或原文档排版。
- 贴图也可通过右键「识别文字并复制」或 Ctrl+Shift+C 识别原始尺寸的图片，不受显示缩放、透明度影响。Esc 先取消识别，再次按 Esc 才关闭贴图。
- 长图预览也可直接 OCR，识别后保留预览。它遵循同样的系统尺寸限制；特别长的图像缩小后文字可能太小，建议分段截图识别。

## 设置

点击主窗口的「设置」，或右键托盘图标 →「设置…」。设置分为 **外观、常规、快捷键** 三页，使用原生输入框、勾选控件和按钮，统一跟随系统深浅色、高对比度和显示缩放。修改在点击「保存」后应用；取消或关闭设置窗口不会保存。

- **外观**：默认勾选「使用 Windows 系统强调色」。也可点击八种预设色，或使用 Windows 原生选色器设置任意颜色；选色后自动切换为自定义模式，再勾选即可恢复跟随系统。设置窗口即时预览按钮和选区配色，保存后应用到整个 Imago，下次启动仍保留。深浅背景继续跟随系统；高对比度启用时优先使用系统可访问颜色。主题色与标注的绘图颜色分别设置。
- **常规**：设置窗口吸附、开机自启和启动时检查更新，说明后台运行行为。
- **快捷键**：在原生快捷键输入框中直接按键，可分别修改截图和剪贴板贴图的全局快捷键。支持 Ctrl/Alt 组合（可加 Shift）、单独 F1–F11 或 Print Screen；两个绑定不能重复，F12 由系统保留。点击「截图使用 Print Screen」可直接填入该按键；新组合被占用或保存失败时保留原有绑定，保存成功立即生效。编辑界面的 M、Shift+M、Ctrl+S 等局部快捷键保持固定。

「界面动效」可独立关闭。开启时，按钮悬停颜色渐变、设置页指示条移动、工具／样式面板展开与收起使用约 140 ms 的缓出过渡；选中工具或开始绘制时立即收起，保持操作直接。原生托盘和贴图右键菜单沿用 Windows 自身的菜单动画。Windows 关闭客户端动画、菜单动画或启用高对比度时，相关过渡自动停用。动效只在交互期间启用计时器，完成或窗口销毁后释放，不在后台持续刷新。

系统强调色使用 Windows [`UISettings.GetColorValue`](https://learn.microsoft.com/en-us/uwp/api/windows.ui.viewmanagement.uisettings.getcolorvalue) 的 Accent 值，并响应系统主题／颜色变化；动画偏好通过 [`SystemParametersInfo`](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-systemparametersinfow) 读取，不修改 Windows 的全局设置。

Print Screen 如果被 Windows 截图工具或其他程序占用，需要先关闭相应按键映射，或使用其他组合。Imago 不自动修改 Windows 的键盘设置。

同一窗口可关闭自动窗口吸附。设置保存到 `%LOCALAPPDATA%\Imago\settings.ini`，下次启动自动读取；取消不会保存修改。截图编辑期间需先完成或取消截图，再打开设置。

「开机自启」默认关闭。勾选并保存后，在当前用户的 Windows 登录启动项中注册运行本程序并附带 `--background`，登录后仅驻留托盘，不弹主窗口，也不需要管理员权限；取消勾选并保存会移除本程序的启动项。自启状态直接读取当前用户的 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\Imago`，不创建服务或计划任务；设置文件保存失败时尝试恢复原有启动项。

便携版自启指向保存设置时运行的 EXE 路径。移动文件或更换版本目录后，在新位置打开程序并重新保存自启设置；Windows「启动应用」中的禁用状态仍可能阻止启动。恢复默认会将自启取消勾选，点击保存后才生效。

## 检查更新

主窗口和托盘的「检查更新」从 GitHub 查询最新正式 Release。发现新版后可打开官方下载页；不会自动下载或安装。
默认在启动约 10 秒后尝试检查，距离上次检查至少 24 小时；设置 → 常规可关闭自动检查。
手动检查会显示当前版本、可用版本或具体失败原因；自动检查失败保持安静，采集期间延后显示更新提示。
更新前先从托盘退出旧版，再替换程序。更多信息见 [隐私说明](PRIVACY.md)。

## 贴图

| 操作 | 快捷方式 |
| --- | --- |
| 贴出剪贴板图片 | Ctrl + Alt + P（默认，可在设置中修改） |
| 移动贴图 | 拖动图片 |
| 缩放贴图 | 鼠标滚轮 |
| 调整透明度 | Ctrl + 鼠标滚轮 |
| 恢复原始大小 | 双击 / 右键菜单 |
| 复制原图 | Ctrl + C / 右键菜单 |
| 保存 PNG 原图 | Ctrl + S / 右键菜单 |
| 识别原图文字并复制 | Ctrl + Shift + C / 右键菜单 |
| 关闭当前贴图 | Esc / 右键菜单 |

贴图默认置顶，可在右键菜单关闭置顶。复制和保存始终使用原图尺寸，不受显示缩放、透明度影响。贴图中的标注已合成为像素，不能重新编辑；关闭后释放图片。

快捷键被其他应用占用时会提示，托盘操作仍可使用。命令行 `Imago.exe --background` 只启动托盘；`Imago.exe --capture` 直接进入截图。
