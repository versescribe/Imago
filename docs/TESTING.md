# 验证范围

## 自动化

`./tools/build.ps1 -RunTests` 在本机显式触发；GitHub CI 默认执行：

- 选区与裁剪边界、负值／溢出限制。
- DIB／DIBV5 行序、透明度、掩码、畸形输入。
- 更新版本的数值比较、降级保护、非法标签、草稿与安装包就绪状态、异常 JSON。

这些测试不启动 Imago，不读取屏幕／麦克风，不访问网络，也不修改真实剪贴板。
`tests/capture_fixture.cpp` 仅是手动验证辅助窗口，不纳入 CI 的 CTest 执行项。

## 手动检查清单

- 截图：自由框选／窗口吸附、移动缩放、标注、撤销、PNG 保存和图片复制。
- OCR／长图：语言能力缺失、无文字、上下滚动、暂停／取消、动态页面对齐失败。
- 录屏：模式互切、范围边框、默认静音、独立／双路音频、暂停恢复、停止与退出。
- 文件：视频复制后关闭工具栏仍可粘贴；取消导出／磁盘不足保留原片；设置保存失败不破坏旧设置。
- 显示：单屏、多屏、负坐标、混合 DPI、深浅色、高对比度。
- 更新：同版、新版、无发行版、断网、限频、关闭启动检查、采集期间不弹窗。
- 生命周期：重复启动、托盘退出、Explorer 重启、休眠与显示器断开。

记录 Windows 版本、Imago 版本和具体复现环境。源码检查、编译、CI 和手动验证分别报告，不相互替代。
